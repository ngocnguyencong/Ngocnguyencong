# src/kit/blocks/marketing/hero-centered.tsx

> Last updated: 2026-10-01 | Protection: STANDARD

## Purpose

Copyable centered marketing hero block with headline and actions.

## What It Does

Optional `trust` slot after the actions accepts a link, label, and React avatar nodes for a derived product to supply its own evidence. The default boilerplate landing never uses this slot. The block contains no customer data.

Optional `subtitle` renders a separate second line within the same h1. `lede` is optional; `children` accepts caller-owned content between the headline/copy and actions. Existing callers retain their original layout when these slots are omitted. The boilerplate landing uses a neutral localized title and lede without customer proof or performance claims.

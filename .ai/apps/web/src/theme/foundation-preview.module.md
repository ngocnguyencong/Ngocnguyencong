# FoundationPreview styles

> Last updated: 2026-10-06 | Protection: STANDARD

## Purpose

Styles for the interactive foundation preview wrapper and its neutral sample
records.

## Important Notes

- App-theme tokens carry every color, border, radius, and control treatment.
- Respect keyboard focus, reduced motion, narrow widths, and all localized
  strings. Keep layout properties logical.

## Validation

- Block-specific presentation remains in each copyable block's self-contained
  stylesheet; this module styles only the composed preview.

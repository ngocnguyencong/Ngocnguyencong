# Pagination styles

> Last updated: 2026-10-06 | Protection: STANDARD

## Purpose

Token-only styles for bounded pagination controls.

## Important Notes

- Page status and both controls remain readable at narrow widths and with long
  translated labels.
- Use logical properties, visible focus, and reduced-motion-safe transitions.
- No raw color values or private UI imports.

- Optional `disabled` keeps both pager actions visibly and natively disabled.

## Validation

- The stylesheet uses theme tokens, logical properties, 44px controls, visible
  focus, and reduced-motion-safe feedback.

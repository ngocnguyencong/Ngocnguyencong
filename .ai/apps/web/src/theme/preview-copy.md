# Foundation preview copy

> Last updated: 2026-10-06 | Protection: STANDARD

## Purpose

Generic English/German/Spanish/French strings for the interactive foundation
preview.

## Public API

- `previewCopy(locale?: AppLocale)` returns the localized preview dictionary.
- No product promises, customer claims, or workspace-specific data appear in
  these strings.

## Validation

- Complete state, filter, pagination, details, and overlay labels are provided
  in English, German, Spanish, and French.

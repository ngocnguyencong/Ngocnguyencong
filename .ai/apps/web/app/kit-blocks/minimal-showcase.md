## Purpose

Composed minimal-style showcase on the dev-only `/kit-blocks` browser:
renders the whole minimal marketing set (hero-product → steps-ruled →
feature-story → comparison-ruled → pricing-panel → faq-split → cta-form)
as one realistic page inside `.marketing-theme`, using lucide icons.

- Uses `kit-blocks.module.css` `.showcaseNote`/`.showcaseFrame` styles
  added on the branch.
- Dev-only route — 404s in production like the rest of `/kit-blocks`.

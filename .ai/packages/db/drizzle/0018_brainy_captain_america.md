# packages/db/drizzle/0018_brainy_captain_america.sql

> Last updated: 2026-10-15 | Protection: STANDARD

## Purpose

Creates `user_appearance` — the per-user synced appearance snapshot for
cross-device theme sync (web browsers, desktop webview, mobile).

## Important Notes

- `user_id` text PK references `"user"."id"` with `ON DELETE CASCADE`;
  `preferences` jsonb NOT NULL; `created_at`/`updated_at` timestamptz
  defaults via the schema's shared helpers.
- `preferences` stores the `AppearancePreferences` JSON (style, theme,
  density, radius, font, layout, toastStyle) — opaque to the DB layer;
  catalog validation happens app-side.
- Generated by `pnpm --filter @supastack/db db:generate`; applied locally
  via `db:migrate` on 2026-10-15.

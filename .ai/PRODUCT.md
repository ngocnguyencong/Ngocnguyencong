# PRODUCT.md

## Purpose

Durable product/design context for the modular boilerplate and its demo surfaces.

## Important Notes

- All platform demo surfaces use neutral, replaceable example content. The
  public landing must never present real customer identities, feedback,
  portraits, trust counts, setup estimates, or production marketing claims.
- Demo pricing is illustrative. Fictional testimonial examples live only in the
  development block gallery; the reusable block remains available to products.
- Preserve the explicit black theme, typography, text-only chrome, and
  accessibility/motion boundaries while replacing sample content.

Document the shared responsive shell, four new packs, semantic/control/motion tokens, accessible primitives, and controlled app blocks. The default demo identity remains neutral and black.
